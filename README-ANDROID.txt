Deutsch-Ukrainisches Kompetenzzentrum – Android-App

1. Alle Dateien dieses ZIP in das GitHub-Repository hochladen.
2. GitHub -> Actions -> Build Android APK öffnen.
3. Workflow manuell starten (Run workflow) oder nach Upload automatisch laufen lassen.
4. Nach erfolgreichem Build unten unter Artifacts "DUK-Zentrum-Android-APK" herunterladen.
5. ZIP entpacken, app-debug.apk auf dem Samsung öffnen und installieren.

Die App öffnet: https://de-ua-kompetenzzentrum.vercel.app
Paketname: de.duk.zentrum
Version: 1.0.0
